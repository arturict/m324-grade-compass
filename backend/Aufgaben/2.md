### 2.1.4 Testarten zuordnen

> Ordne die vorhandenen Testklassen einer Testart zu: Unit Test, Controller Test, Repository Test oder Integration Test. Woran erkennst du die Testart im Code?

| Testklasse | Testart | Erkennbar an |
|---|---|---|
| `SubjectServiceTest` | Unit Test| Testet die Service-Logik ohne Controller oder Repository |
| `GradeServiceTest` | Unit Test | Testet die Service-Logik ohne Controller oder Repository |
| `CreateSubjectRequestTest` | Unit Test | Testet die Validierung der Request-Klasse |
| `SubjectControllerTest` | Controller Test | Testet die Endpunkte des Controllers |
| `SubjectRepositoryTest` | Repository Test | Testet die Datenbankoperationen des Repositories |
| `SubjectIntegrationTest` | Integration Test | Testet das Zusammenspiel von Controller, Service und Repository |
| `GradeCompassApplicationTests` | (Unit Test?) | Testet, ob der Spring Boot Kontext korrekt geladen wird | 

**Woran erkennt man die Testart?**
- Unit Tests testen einzelne Klassen oder Methoden isoliert, oft mit Mock-Objekten.
- Controller Tests testen die Endpunkte eines Controllers, oft mit MockMvc.
- Repository Tests testen die Datenbankoperationen eines Repositories.
- Integration Tests testen das Zusammenspiel mehrerer Komponenten (Controller, Service, Repository).
- Tests wie `GradeCompassApplicationTests` prüfen, ob der Spring Boot Kontext korrekt geladen wird, und werden manchmal als Smoke Tests oder Kontext-Tests bezeichnet.

> **Hinweis:** Die Zuordnung stimmt. `GradeCompassApplicationTests` ist aber kein Unit Test, sondern ein **Integration Test** (Smoke Test): `@SpringBootTest` startet die ganze Applikation.
> Die Frage «Woran erkennst du die Testart im Code?» zielt auf die Annotationen über der Klasse:
> - Unit Test: kein Spring, `@ExtendWith(MockitoExtension.class)` mit `@Mock` / `@InjectMocks` (oder gar keine Annotation wie bei `CreateSubjectRequestTest`)
> - Controller Test: `@WebMvcTest(...)`, `MockMvc`, Service mit `@MockitoBean` gemockt
> - Repository Test: `@DataJpaTest`, echtes Repository mit `@Autowired`, H2-Datenbank
> - Integration Test: `@SpringBootTest` (ganze Applikation), nichts gemockt
